Applications

Where MCIS is used

The Maximum Common Induced Subgraph problem underlies structural similarity in a broad range of domains. Below are the primary application areas.

🧪

Cheminformatics

Molecules are naturally modelled as graphs — atoms as vertices, bonds as edges. MCIS computes the Maximum Common Substructure (MCS) between two compounds, enabling scaffold similarity search, virtual screening, and activity-cliff detection.

drug discovery scaffold alignment
🧬

Bioinformatics

Protein–protein interaction networks and metabolic pathways share conserved functional modules. MCIS identifies these conserved subnetworks across species, supporting ortholog detection and pathway alignment in comparative genomics.

PPI networks pathway alignment
🔍

Pattern Recognition

Shapes, scene graphs, and 3-D models can be encoded as attributed graphs. MCIS provides a principled structural similarity score used in image retrieval, document layout matching, and CAD model comparison.

image retrieval scene graphs
🌐

Network Analysis

Detecting recurring structural motifs in communication, social, or cybersecurity graphs often reduces to MCIS. Common subgraph size provides a robust graph-edit-distance lower bound and a symmetry-aware anomaly score.

anomaly detection motif finding
⚙️

Hardware Verification

Equivalence checking between circuit netlists and cross-design re-use analysis both rely on subgraph isomorphism and common-subgraph detection. MCIS gives the largest structurally equivalent block between two netlists.

circuit netlist formal verification
🔐

Software & Malware Analysis

Control-flow graphs (CFGs) and call graphs of binaries can be compared via MCIS to detect code clones, plagiarism, or malware variants — even across compiler optimisations that alter the graph structure superficially.

CFG matching clone detection

SymSplit Algorithm

SymSplit extends the McSplit branch-and-bound framework with dual symmetry breaking: it detects modular symmetries based on local neighbourhood hashes in both the variable graph G and the value graph H, then prunes isomorphic subtrees during search. Variable symmetry (previously exploited by RRSplit) and value symmetry (novel contribution) are composed without violating completeness.

Symmetry detection runs in O(n²) via Boost hash-based neighbourhood grouping. The resulting symmetry classes enable O(1) pruning lookups during BnB traversal.
